# Vextorium

**Pay-per-call data for AI agents and trading bots.** 244 services, paid per call in USDC or RLUSD with [x402](https://x402.org). No sign-up, no API keys; failed calls are never charged.

[![Tested by Lumi](https://api.lumitrades.io/badge/vextorium.svg)](https://api.lumitrades.io/trust/v/vextorium)
[![Listed on mcpservers.org](https://mcpservers.org/badge.svg)](https://mcpservers.org/servers/bru1noia/vextorium-mcp)

## Projects

- [vextorium-mcp](https://github.com/bru1noia/vextorium-mcp): remote MCP server for any MCP client (`https://api.vextorium.com/mcp`)
- [vextorium-python](https://github.com/bru1noia/vextorium-python): Python client (`pip install vextorium`), freqtrade helper included
- [plugin-vextorium](https://github.com/bru1noia/plugin-vextorium): ElizaOS plugin
- [x402-registry](https://github.com/bru1noia/x402-registry): community listing proposals for x402 APIs
